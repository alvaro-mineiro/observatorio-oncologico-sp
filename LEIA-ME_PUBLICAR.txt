PUBLICAR NO VERCEL (uma vez instalado o Node.js: https://nodejs.org)
  1. No Terminal:   cd "/Users/alvaromineiro/Documents/anan_data/analise_quanti_projeto/observatorio_site"
  2. Primeira vez:  npx vercel@latest login          (entra com a conta do Vercel/GitHub)
  3. Publicar:      npx vercel@latest deploy --prod
     Na primeira publicação ele pergunta o nome do projeto (ex.: observatorio-oncologico-sp):
     aceite os padrões ("Framework: Other", sem comando de build, diretório ".").
  4. O endereço aparece no fim (https://<nome>.vercel.app). Ponha-o em CFG["URL_PUBLICA"] no gerador
     e gere de novo, para ele sair nos relatórios e nos links compartilháveis.
  Para atualizar: rode o gerador (a pasta é refeita) e repita o passo 3.
  Limite: no plano gratuito (Hobby) o Vercel aceita até 100 MB de arquivos por publicação feita pela linha de
  comando (o log do gerador mostra o total do site). Acima disso: plano Pro, ou uma das opções abaixo.
  O plano Hobby é para uso não comercial; para um site institucional, confira os termos ou use o Pro.

PUBLICAR NO GITHUB PAGES (até 1 GB; repositório só com esta pasta)
  1. Crie um repositório novo em https://github.com/new (ex.: observatorio-oncologico-sp), sem README.
  2. No Terminal, dentro desta pasta:
       git init && git add . && git commit -m "Observatório" && git branch -M main
       git remote add origin https://github.com/SEU_USUARIO/observatorio-oncologico-sp.git
       git push -u origin main
  3. No repositório: Settings → Pages → Deploy from a branch → main / (root) → Save.
  Para atualizar (sem acumular versões antigas: a pasta dados/ é refeita a cada geração e, guardando o
  histórico, o repositório cresceria até estourar o limite de 1 GB), rode o gerador e, nesta pasta:
       git checkout --orphan nova && git add -A && git commit -m "Atualização"
       git branch -D main && git branch -m main
       git push -f origin main && git gc --prune=now
  O GitHub recusa arquivos acima de 100 MB (o log do gerador mostra o maior arquivo do site).
